# Avatares dos narradores

Lia, Caio e Ravi são personagens fictícios gerados para o ProjectLecture. As imagens não representam pessoas reais e servem apenas como identidade visual das vozes.

Direção visual compartilhada: retrato editorial 3D polido, enquadramento quadrado, expressão acolhedora, iluminação suave de estúdio, fundo em azul-marinho e violeta, sem texto ou logotipos.

- `lia.png`: narradora jovem, serena e acolhedora;
- `caio.png`: narrador jovem, objetivo e contemporâneo;
- `ravi.png`: narrador maduro, calmo e reflexivo.
